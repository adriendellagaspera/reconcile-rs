Architecture

Embedded replicas · local state · range-based reconciliation

RuntimeRSOS storageReconciliationMessaging

Cluster

Every authoritative replica owns the complete dataset and can originate writes.

Local availability

Reads use local state. Writes do not wait for an agreement with other replicas.

Eventual convergence

Propagation and anti-entropy repair differences once communication permits it. Partitions can leave conflicting states.

Replica roles

Authoritative replicas own dated entries. ReadReplicaMap is a value-only sink, outside authoritative tombstone stability.

Runtime

The facade composes storage, clocks, merge semantics, reconciliation and platform adapters.

Clock order

Timestamp = HLC physical time + logical counter + NodeId. The node identity supplies a deterministic tie-break.

Lifecycle

Tokio on native targets; worker-local tasks and timers in browsers. Cancellation stops owned tasks and triggers final persistence handling.

Observed state

sync_state, counters and immutable snapshots expose activity. An initiated round is not a guarantee of cluster-wide agreement.

RSOS backend

FingerprintTreeMap: ordered persistent storage with range cardinality and fingerprint aggregates.

Structural sharing

Unchanged nodes are shared through Arc. Existing snapshots stay valid while a writer publishes a newer root.

Read path

Point reads and snapshots do not hold the writer lock. Writers serialize mutation and root publication.

Storage semantics

RSOS provides ordering and aggregates. HLC, LWW decisions, replication and tombstone stability belong to its caller.

Range reconciliation

RBSR compares range summaries; the runtime transports comparisons and enumerated content.

01

Summarize

Capture an immutable local tree and advertise range count + fingerprint.

02

Compare

Matching summaries end that comparison. A differing range needs more work.

03

Refine

Split and compare smaller ranges, or enumerate according to policy. Splits must make progress.

04

Exchange

The runtime sends entries from differing ranges through bounded, framed messaging.

05

Merge / repeat

LWW merges dated entries. Later rounds repair losses and concurrent changes.

Summary equality is a fingerprint-based comparison. The playground reports agreement using exact dated entries. A matching value with a different timestamp is not the same authoritative entry. This diagram is not a bandwidth benchmark.

Network and admission

Authentication and replay validation precede protocol handling and domain mutation.

Authenticate

Admit peer

Apply topology / membership capacity rules before allocating protocol state.

Validate replay stamp / sequence and bounded replay state.

Reassemble

Process complete frames, fragments or negotiated recovery controls within bounded state.

05

Only complete admitted payloads reach reconciliation and merge.

Framing and repair

Default datagram budget: 1200 bytes including framing/authentication overhead. Selective fragment recovery is capability gated; peers without it retain whole-message anti-entropy fallback. Retained transfer state is bounded by count, bytes and lifetime.

Transport boundary

The current public facade uses SocketAddr endpoints. Native adapters include UDP and in-memory transport; decorators supply impairments. Browser callers supply in-memory/custom transport. UDP binding and DNS return Unsupported in the browser.

Identity / configuration Purpose
NodeId Writer identity in HLC timestamps and deterministic ordering.
Transport endpoint Address used for discovery, routing and current live peer participation. Distinct from the clock identity.
ClusterKey Shared authentication material and derived keyed fingerprint lift. All participating nodes need compatible provisioning.
Discovery / membership Routing peers and authoritative causal-stability membership are different concerns. Decommissioning changes the stability obligations.

Deletion and durability

A deletion is replicated state; persistence is a separate capability.

Optional persistence

Restore values, tombstones and causal-stability state before network participation. The generic Persistence port supports complete state; FileSnapshot can publish incremental generations.

FileSnapshot generations

Open → frozen → committed. An authoritative manifest names an immutable base plus ordered deltas. Publish durable data before the manifest; failed generations remain retryable. Compaction and recovery preserve the same coherent state boundary.

The playground uses real replicas with in-memory storage and a synthetic connectivity gate. It exercises local writes, range deletion, partitions, merge and reconciliation. Persistence and recovery diagrams describe library capabilities; the playground does not exercise disk recovery or provide consensus or exclusive task ownership.
